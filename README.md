# DiceyDiplomat

Dicey Diplomat is conversation simulator that uses card battler mechanics as dialogue options
The main character, Dicey, has 6 personalities for each face on their die head
The personalities shift depending on Dicey's mood which is impacted by the last card played, and what Rat Burglar has said to them
